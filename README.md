# Сутінковий сад — детективна рольова гра

Адмін-панель + сторінка гравця для детективної рольової гри. Ведуча керує грою з
телефону/комп'ютера, гравці заходять зі своїх телефонів і отримують випадкову
унікальну картку персонажа.

## Як це працює

1. Ведуча відкриває `/admin`, вводить пароль доступу.
2. Вказує кількість гравців (3–10) і тисне «Почати нову гру» — сервер готує
   рівно стільки унікальних ролей, скільки гравців, одна з них завжди вбивця.
3. Гравці заходять на головну сторінку (`/`), вводять ім'я і тиснуть
   «Отримати роль» — кожен отримує свою унікальну картку і більше її не втрачає:
   роль прив'язується до нього через cookie, тож при оновленні сторінки або
   розблокуванні телефону картка не змінюється і повторно не видається іншому.
4. На `/admin` ведуча в реальному часі (оновлення кожні 3 сек) бачить імена всіх
   гравців, що приєдналися, разом з їхніми повними картками (включно з тим, хто
   вбивця). Гравці бачать тільки власну картку.

## Запуск локально

```bash
cd murder-mystery-app
npm install
npm start
```

Сервер підніметься на `http://localhost:3000`.
- Сторінка гравця: `http://localhost:3000/`
- Адмін-панель: `http://localhost:3000/admin`

Пароль адмінки за замовчуванням: `detective2026`
(можна змінити змінною середовища `ADMIN_PASSWORD`).

Щоб гравці з телефонів могли зайти, коли ти запускаєш локально — треба бути в
одній Wi-Fi мережі і відкрити `http://<твоя-локальна-IP>:3000` замість
localhost (IP комп'ютера можна подивитись командою `ipconfig getifaddr en0` на
Mac або `ipconfig` на Windows).

## Деплой на Render

1. Заливаєш цю папку в репозиторій на GitHub.
2. На [render.com](https://render.com) створюєш **New Web Service**, підключаєш
   репозиторій.
3. Налаштування:
   - Build Command: `npm install`
   - Start Command: `npm start`
4. У розділі Environment додаєш змінну `ADMIN_PASSWORD` зі своїм паролем.
5. Після деплою Render видасть публічне посилання — його й роздаєш гравцям
   (`https://твій-додаток.onrender.com`), а сама заходиш на
   `https://твій-додаток.onrender.com/admin`.

⚠️ Безкоштовний тариф Render "засинає" після періоду бездіяльності — перший
запит після сну може займати 30–60 секунд. Дані гри зберігаються в пам'яті
сервера, тому рестарт сервера (в т.ч. після сну на free tier) скидає всі ролі —
для одноразової гри за вечір це не проблема, просто не рестартуй сервер
посеред гри.

## Зміна сценарію

Сценарій (жертва, 10 персонажів, хто вбивця) знаходиться в
`data/scenario.js`. Можна редагувати описи, стосунки з жертвою, секрети
напряму в цьому файлі. Порядок у масиві `ORDER` визначає, які ролі підключаються
першими, коли гравців менше 10 — вбивця (`olena`) стоїть першим, тому присутній
у грі за будь-якої кількості гравців від 3 до 10.
